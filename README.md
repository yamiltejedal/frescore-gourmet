# Frescore Gourmet — sitio web

Sitio estático (HTML/CSS/JS) para Frescore Gourmet, estaciones gastronómicas para eventos.

- `index.html` — página única
- `assets/img`, `assets/video` — medios optimizados (WebP / MP4 sin audio)
- `assets/js` — GSAP 3.12.5, ScrollTrigger y Lenis 1.1.13 (copias locales)

Despliegue: GitHub Pages (rama `main`, raíz) o Netlify arrastrando la carpeta.
